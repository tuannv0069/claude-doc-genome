# Project lesson router

## §1 Read applicable working-method records

At the start of each new task, read this router before deciding whether a work type matches. Read every matching store and its named checking stores for one hop only. Reuse an unchanged selection while the action remains the same. An empty table is valid and requires no invented lesson.

| file | work type | paired guide | checks |
|---|---|---|---|

Register new stores when they are created. Recording, phase selection and escalation follow `.agent-workspace/guide/general/lesson-capture.md` §2. A paired guide is optional. Keep checking relationships acyclic and pass the selected paths when delegating.

## §2 Shared use

This router and its stores belong to the project genome. Every supported agent reads and writes the same lesson history so a correction learned by one agent changes later work by the others.
