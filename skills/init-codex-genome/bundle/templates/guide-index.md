# Project guide router

## §1 Project placement

The project genome uses `.agent-workspace/` for guidance, records, tooling and temporary task state shared by its agents. The project's finished work products remain in their project-owned area. No placement migration is currently recorded. Add an unresolved migration here with its destination when one is identified; remove it once resolved.

Read the row that matches the operation being performed. Each target identifies the owning procedure; its entry here does not copy that procedure or prove that it has already been read.
