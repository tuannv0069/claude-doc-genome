# Project decision journal

## §1 Find standing reasons

Search dated decision files by their subject path and section before changing a governing requirement or reversing an earlier choice. Follow explicit supersession links to identify which decision stands. A newer unrelated file does not replace an earlier one.

Entries live in year-month directories and follow `.agent-workspace/guide/general/decision-journal.md` §3. This project has no declared shard-volume threshold. Introduce one only when its maintenance use is established.

## §2 Preserve history

Record decisions that govern work in this project regardless of which supported agent makes them. Keep historical decisions unchanged and supersede them when new evidence changes a conclusion.
