- decided: Route software tasks to the software roles and allow creative work to use a project-specific role or the no-match path. General planning does not automatically receive software architecture checks.
- because: A shared word such as script or artifact does not make narrative work a software implementation. Applying branch coverage or runtime acceptance to creative work confuses the responsibilities the user wants to isolate.
- rejected: Keeping broad router rows while placing exclusions inside the selected roles would still load unrelated criteria before the task could choose its own domain.
